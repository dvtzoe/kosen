# Challenge 2 — `max_of_three` (no built-in `max`)

Write a function:
```python
def max_of_three(a, b, c):
    """Return the largest among a, b, c (int/float)."""
```

### Requirements
- Accept `int` or `float` for all three inputs
- Correct for negative numbers and mixed floats
- If there is a tie, simply return that value
- **Do not** use Python's `max()`

Run tests:
```bash
pytest -q
```
